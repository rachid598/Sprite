# Consignes du projet Spiritdex

## Source de référence des mises à jour

Instruction permanente de Rachid, mise à jour le 28 novembre 2026 (en
remplacement de `soiscoolmec.com`, devenu inaccessible) :

Quand Rachid demande de mettre à jour le site ou l'application, se baser en
priorité sur **Neko-V** : <https://neko-v.com/index.php?page=spriteDex>, avec
**Fortnite.GG** : <https://fortnite.gg/sprites> comme source secondaire de
secours et de recoupement.

- Consulter le catalogue Neko-V à jour et le comparer à la version du projet.
- Utiliser Neko-V comme référence principale pour les saisons, les esprits, les
  variantes, leurs disponibilités, les noms français, les effets et les visuels.
- Utiliser Fortnite.GG en secours si Neko-V est indisponible ou incomplet, et en
  recoupement pour vérifier les nouveaux ajouts, les variantes et les visuels
  directement issus des fichiers du jeu (en signalant les noms français encore
  à confirmer si Fortnite.GG est utilisé seul).
- Les autres sources (ex. SpriteLocker FR, notes Epic Games) servent uniquement
  à compléter ou à recouper les informations. Ne pas remplacer silencieusement
  les données Neko-V par celles d'un autre site. Signaler les contradictions et
  les informations absentes.
- Placer les éléments indiqués indisponibles dans les données « à venir »,
  exclus des compteurs de progression publiés.
- Préserver les identifiants, les positions historiques des liens de partage,
  les sauvegardes et les collections des anciennes saisons.

Cette instruction s'applique aussi aux demandes générales comme « mets à jour
le site » ou « mets à jour l'appli », même si Rachid ne rappelle pas le nom ou
l'adresse des sources.
