# Consignes du projet Spiritdex

## Source de référence des mises à jour

Instruction permanente de Rachid, enregistrée le 1er novembre 2026 :

Quand Rachid demande de mettre à jour le site ou l'application, se baser sur
**SoisCool Mec** : <https://soiscoolmec.com/index.php?page=spriteDex>.

- Consulter le catalogue à jour et le comparer à la version du projet.
- Utiliser SCM comme référence principale pour les saisons, les esprits, les
  variantes, leurs disponibilités, les noms français, les effets et les visuels.
- Les autres sources servent uniquement à compléter ou à recouper les informations.
  Ne pas remplacer silencieusement les données SCM par celles d'un autre site.
  Signaler les contradictions et les informations absentes.
- Placer les éléments indiqués indisponibles dans les données « à venir »,
  exclus des compteurs de progression publiés.
- Préserver les identifiants, les positions historiques des liens de partage,
  les sauvegardes et les collections des anciennes saisons.

Cette instruction s'applique aussi aux demandes générales comme « mets à jour
le site », même si Rachid ne rappelle pas le nom ou l'adresse de SCM.
